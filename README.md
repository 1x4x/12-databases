
# Exercise 3 – Short Explanations

## 1. What is Load Balancing?
Load balancing means distributing traffic and workloads across multiple servers so that no single server becomes overloaded.

## 2. Give an Example of When Load Balancing Is Useful
For example, an online store during Black Friday when many people visit the website at the same time. Load balancing helps distribute visitors across multiple servers.

## 3. Three Benefits of Using Load Balancing for a Website
1. **Faster Website** – Traffic is distributed so the website does not become slow.
2. **Better Availability** – If one server stops working, other servers can continue handling requests.
3. **Handles More Visitors** – The website can support many users at the same time.

## 4. What is SQL Server Replication?
SQL Server Replication is a feature that copies and synchronizes data between different SQL Servers so that the same information can be available in multiple locations.

## 5. What is Mirroring in SQL Server?
Database Mirroring means creating a copy of a database on another server. If the main server fails, the backup server can take over.

## 6. What are AlwaysOn Availability Groups in SQL Server?
AlwaysOn Availability Groups is a feature that allows multiple servers to maintain copies of the same databases. If the primary server fails, another server can take over to keep the databases available.

## Summary: Key Differences

| Feature | Description |
|---------|-------------|
| **Replication** | Copies and distributes data between servers. |
| **Mirroring** | Maintains a standby copy of a database on another server. |
| **AlwaysOn Availability Groups** | Provides high availability for a group of databases across multiple servers. |
